# Playwright Daily Lab

Personal learning project for practicing Playwright with TypeScript.

## Goal

Study Playwright regularly in short 30-minute sessions and build a collection of practical examples that can be reused as a reference for QA Automation work.

## Learning approach

Each session focuses on one small Playwright topic:

1. Understand what the feature does.
2. Review a few simple examples.
3. Implement a small practical task.
4. Run and verify the test.
5. Save the final working example in the project.

## Run tests

Run all tests:

```bash
npx playwright test
```

Run tests in headed mode:

```bash
npx playwright test --headed
```

Run tests using Playwright UI Mode:

```bash
npx playwright test --ui
```
