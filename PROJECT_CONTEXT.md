# Playwright Daily Lab — Project Context

## Purpose

This is a personal learning project for daily Playwright practice.

The main goal is to study Playwright in short focused sessions and gradually build a reusable collection of practical examples for QA Automation work.

## Learning format

Each session should focus on one small Playwright topic.

Typical flow:

1. Short explanation of the concept.
2. Two or three small examples.
3. One practical task completed independently.
4. Review and correction.
5. Save the final working example in the repository.
6. Update learning documentation when relevant.

## Tech stack

- Git

- VS Code — writing and running tests

## Repository structure

- `tests/` — practical Playwright examples
- `docs/ROADMAP.md` — learning roadmap
- `docs/LEARNING_LOG.md` — completed sessions
- `docs/CHEATSHEET.md` — quick syntax reference
- `docs/PLAYWRIGHT_NOTES.md` — detailed explanations
- `AGENTS.md` — instructions for Codex
- `PROJECT_CONTEXT.md` — shared project context

## Principles

- One small topic at a time.
- Prefer practical examples over theory-only notes.
- Keep examples simple and focused.
- Do not introduce complexity without a reason.
- Prefer Playwright best practices.
- Keep working examples as future reference.
- Learn through writing and running code, not only reading.
